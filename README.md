# KindKart

KindKart is a modern student community marketplace and donation platform built using Flask.

## Features

- Student Marketplace
- Donation Campaigns
- NGO Dashboard
- Donor Dashboard
- Admin Dashboard
- Authentication
- Responsive Design
- Modern UI

## Tech Stack

- Flask
- HTML5
- CSS3
- JavaScript
- SQLite

## Installation

```bash
pip install -r requirements.txt
```

Run

```bash
python app.py
```
